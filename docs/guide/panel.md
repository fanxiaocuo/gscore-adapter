# Web 面板

装了 **QQBot-Web-Adapter** 的话，它的控制台左侧会多一页「早柚核心适配器」☄️，连接状态与配置都能点着改。装了[锅巴](https://github.com/guoba-yunzai/guoba-plugin)也可以在锅巴面板里改配置。

## 面板里有什么

- 连接的实时状态
- 今日 / 累计中转计数
- 连接的增删改与启停
- **绑定账号管理**：连接卡片上的「绑定」标签可以点开（缩起时预览头像），展开后每个绑定账号一行——头像、昵称、账号、在线状态，点「移除」解绑；下方列出在线但未绑定的机器人，点一下即绑定到该连接
- 全局设置

页面里用的是插件自己的图标；导航栏那颗只能是 emoji，宿主按纯文本渲染它。

## 绑定管理的几个细节

- 移除**最后一个**绑定会弹确认——之后连接变为「不限账号」，所有机器人的消息都会转发
- 绑定的账号同时在排除名单（`exclude`）里时，会标红「已被排除，不会转发」——排除优先级高于绑定，这种组合等于白绑
- 头像优先读适配器挂在机器人实例上的值；离线账号按号从 qlogo 兜底，实在取不到显示首字圆
- 增删走的就是「编辑连接」接口，保存后该连接自动重连生效；每个绑定账号会单独写入 `bot_id_map`，折叠区会标出该账号的平台标识。锅巴里改绑定账号同样会补进这张表

## 不是自带服务器

::: warning 面板不自带服务器
它是挂在 **QQBot-Web-Adapter** 这个宿主上的插件页。宿主没装时这部分就是死代码，不影响插件其余功能。
:::

宿主开机时扫 `webadapter/index.js` 并注册页面与接口，接口由宿主统一加登录鉴权——非内网直接 403。也就是说鉴权不是插件自己做的，跟着宿主那一套走。

## 改配置的行为

改配置走的是和指令同一条路径，**yaml 里的注释会保留**。

一处例外要知道：心跳参数改了会自动重连一次。

token 在面板上只显示「已配 token」，不回原值，留空保存表示不改动。
