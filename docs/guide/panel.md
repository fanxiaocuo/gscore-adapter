# Web 面板

装了 **QQBot-Web-Adapter** 的话，它的控制台左侧会多一页「早柚核心适配器」☄️，连接状态与配置都能点着改。装了[锅巴](https://github.com/guoba-yunzai/guoba-plugin)也可以在锅巴面板里改配置。

## 面板里有什么

- 顶部四块概览：**连接**（已连接 / 运行时条数，括号里是逻辑配置条数）、今日上行、今日下行、适配器开关
- 连接卡片：实时状态、绑定账号、收发计数，以及停用 / 编辑 / 删除
- 展开阶段被跳过的连接（地址解析不了、没有绑定账号、路径撞车……）在连接区顶上单列一条「有连接没能启动」，写明是哪一条、为什么
- **绑定账号管理**：卡片上的「绑定 N 个账号」标签点开就是逐账号的开关列表，见下
- 全局设置

页面里用的是插件自己的图标；导航栏那颗只能是 emoji，宿主按纯文本渲染它。

## 一条卡片，多条 ws

配置里一条连接在运行时是 N 条 ws（一个绑定账号一条，理由见[配置](./config.md)）。面板按这个层级显示：

- 卡片顶行是**聚合状态**：任一账号连上就算这个核心通了；重连次数取各账号里最差的那个
- 展开绑定区、或这条连接有多条运行时连接时，卡片下方逐条列出运行时连接：状态点、运行时名字（`连接名 [账号]`）、路径、状态与重连次数
- 路径只显示到 pathname，不含任何查询参数

## 绑定账号的开关列表

点卡片上的「绑定」标签展开。缩起时那个标签本身就是摘要：最多三个已绑定账号的头像叠在一起，后面跟「绑定 N 个账号」（兼容连接一个账号都没绑时显示「不限账号」）。

展开后一行一个机器人：

| 列 | 内容 |
| :--- | :--- |
| 头像 | 适配器给的头像；取不到按号回退 qlogo，再取不到显示首字圆 |
| 昵称 / 账号 | 昵称取不到时显示「未知昵称」；下面一行是 `self_id`（等宽字体） |
| 平台胶囊 | 该账号在 `bot_id_map` 里的平台标识，推断不出时显示「未识别」，不伪装成默认值 |
| 在线状态 | 「在线」或「离线 · 已保留」 |
| 开关 | Apple 风格绿色开关，拨一下立刻保存 |

几处语义要留意：

- **候选是「在线的全部机器人 ∪ 本连接绑过的账号」**。离线但已绑定的号不会消失，仍然能在这儿解绑；从没绑过又不在线的号进不了列表，只能在「编辑」弹层的绑定账号框里手填
- **开关的开合看的是有效账号**（在 `bind` 且不在 `exclude`）。两边都写了的号灰着，同一行挂一句红字「已被排除，不会转发」——绿着却不转发是在说谎。把它拨开会顺手从排除名单里放出来，一步自愈
- **拨一下就是一次保存**，不用再点确定；请求在途时整组开关禁用（行上显示「保存中…」），避免连点把状态叠乱
- **只动这一个账号**：面板的绑定开关走的是单账号动作，开就只起那个账号那一条 ws，关就只停那一条，同一个核心上其他账号不会跟着断一次。指令的 `bind+=` / `bind-=` 是整条先停后起
- 每次绑定会把该账号的平台标识写进 `bot_id_map`；取消绑定不删这张表的记录（下次绑回来还能用），也不会替你写 `exclude`

### 最后一个开关

只填 `host:port` 的连接（面板上叫「自动连接」）最后一个开关是**禁用**的，旁边写着「最后一个绑定，不能关」：核心侧的客户端标识就是 `/ws/Yunzai-<账号>`，一个账号都不绑等于这条连接不存在，拨了也只会挨一个 400。真不想连了就停用或删除整条连接。

写了自定义路径的兼容连接没有这条限制，但两个方向都会先弹确认——它只有一条 ws，`bind` 在它上头是转发过滤器：

- 关掉最后一个：白名单变不限账号，其余机器人的消息**突然全部开始**转发
- 从不限账号拨开第一个：不限变单账号白名单，其余机器人的消息**当场全部停止**转发

## 新增 / 编辑连接的弹层

字段是连接名、核心地址、token、重连间隔、最大重连次数、绑定账号、排除账号。地址栏的提示写着「只填 host:port，运行时按绑定账号生成 `/ws/Yunzai-<账号>`」。

- 绑定账号框与下方的开关列表是**同一份数据**：框是手填入口（离线且从没绑过的账号只能手写），开关是常规入口
- 弹层里的开关不即时保存，跟其余字段一起提交；中途关掉等于没改
- 地址填成 `host:port` 而一个账号都没开时，保存按钮灰掉并在下面说明理由。真正的把关仍在后端

## 手机上也能用

面板是响应式的，720px 以下换一套排布：连接卡片的按钮组整组换行靠右，机器人行从四列改成三列——头像与开关跨两行钉在两端，平台、在线状态这些元信息挪到昵称下面一行。开关的触控区固定 44px 高。禁用理由一律写成**可见**文字而不是 tooltip：触屏上没有 hover。

## 不是自带服务器

::: warning 面板不自带服务器
它是挂在 **QQBot-Web-Adapter** 这个宿主上的插件页。宿主没装时这部分就是死代码，不影响插件其余功能。
:::

宿主开机时扫 `webadapter/index.js` 并注册页面与接口，接口由宿主统一加登录鉴权——非内网直接 403。也就是说鉴权不是插件自己做的，跟着宿主那一套走。

## 改配置的行为

改配置走的是和指令同一条路径，**yaml 里的注释会保留**。

一处例外要知道：心跳参数改了会自动重连一次。

锅巴那边是整表写回连接列表（地址栏的说明同样是「只填到 host:port」），保存后会自动把绑定账号补进 `bot_id_map`，并重建全部连接。

## 面板看不到 token

接口只回一个布尔 `has_token`，说明这条连接配没配凭据，**从不回原值**——面板上显示成「已配 token」这个标签，编辑时留空表示不改动。地址也是脱敏后才回给浏览器：查询串、fragment 与 userinfo 一律砍掉，运行时连接只给到 pathname。截图发出去不会连带把凭据发出去。
