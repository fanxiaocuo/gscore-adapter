# Web 面板

装了 **QQBot-Web-Adapter** 的话，它的控制台左侧会多一页「早柚核心适配器」☄️ —— 连接状态和配置都能点着改，不用记指令。装了[锅巴](https://github.com/guoba-yunzai/guoba-plugin)也能在锅巴面板里改配置，项目少一些，见[锅巴那边](#锅巴那边)。

::: warning 面板不自带服务器
它是挂在 QQBot-Web-Adapter 这个宿主上的插件页。宿主没装时这部分就是死代码，不影响插件其余功能。登录鉴权也是宿主那一套，不是插件自己做的。
:::

## 页面长什么样

顶上四块概览三个页面都看得见：**连接**（已连接 / 实际条数，括号里是配置了几条）、今日上行、今日下行、适配器是否启用。右上角两个按钮：刷新、全部重连。

下面是三个 tab：

| tab | 内容 |
| :--- | :--- |
| **连接** | 连接卡片列表 + ws 开关与心跳两项 |
| **设置** | 总开关、媒体与外链、内置文件服务、更新检查 |
| **过滤** | 上报开关、前缀与关键词、群名单、用户名单 |

选中哪一页记在浏览器里，下次打开还是那一页；左右方向键也能切。页面每 10 秒自己刷一次数据。

## 连接页

「添加连接」在标题右边。每条连接一张卡片：

- 顶行是状态点、连接名、核心地址，底下一行依次是状态、`已重连 N 次`、`已配 token`、被排除的账号、`↑上行 ↓下行`
- 右边三个按钮：停用（或启用）、编辑、删除
- 卡片最底下一整行是账号折叠开关，见[下一节](#管绑定账号)

有连接压根没启动时（地址解析不了、没绑账号、和别的连接撞了同一条路径……），连接区顶上会多一个红框「有连接没能启动」，逐条写明是哪一个、为什么。另有一个黄框「连接已启动，但有需要注意的地方」—— 那些连接照常在跑，只是有事要告诉你。

卡片列表下面是 ws 那三项：启用 ws 通路、心跳间隔（秒）、心跳超时（秒）。

## 管绑定账号

卡片底部那**一整行**就是开关：左边是最多三个已绑账号的头像叠在一起，跟着「绑定 N 个账号」（地址里写了路径又一个账号都没绑的连接显示「不限账号」），右边写着「管理 ▼」，点一下展开、变成「收起 ▲」。

展开后一行一个机器人：

| 列 | 内容 |
| :--- | :--- |
| 头像 | 适配器给的头像；取不到按号回退，再取不到显示首字圆 |
| 昵称 / 账号 | 昵称取不到时显示「未知昵称」，下面一行是账号 |
| 平台 | 该账号在 `bot_id_map` 里的平台标识，推断不出时显示「未识别」，不拿默认值糊弄 |
| 状态 | 「在线」或「离线 · 已保留」；这个号那条 ws 的状态、重连次数、收发数、路径也在这一行 |
| 开关 | 拨一下立刻保存 |

几处要留意：

- 候选是「在线的全部机器人 + 这条连接绑过的账号」。离线但绑过的号不会消失，还能在这儿解绑；从没绑过又不在线的号只能在「编辑」里手填
- 开关的开合看的是**实际生效**的账号：同时写进 `bind` 和 `exclude` 的号灰着，同一行挂一句红字「已被排除，不会转发」。把它拨开会顺手从排除名单里放出来
- 拨一下就是一次保存，不用再点确定。请求在途时整组开关禁用，行上显示「保存中…」
- **只动这一个账号**：开就只起那个号那一条 ws，关就只停那一条，同一个核心上别的号不会跟着断一次。指令的 `bind+=` / `bind-=` 是整条先停后起

### 最后一个开关关不掉

只填 `host:port` 的连接（面板上叫「自动连接」），最后一个开关是灰的，旁边写着「最后一个绑定，不能关」—— 核心侧就是靠 `/ws/Yunzai-<账号>` 这条路径认客户端的，一个账号都不绑等于这条连接不存在。真不想连了就停用或删除整条。

地址里写了路径的（面板上叫「兼容连接」）没有这条限制，但两个方向都会先弹确认：它只有一条 ws，`bind` 在它上头只是转发白名单。

- 关掉最后一个：白名单变不限账号，其余机器人的消息**突然全部开始**转发
- 从不限账号拨开第一个：其余机器人的消息**当场全部停止**转发

## 新增 / 编辑连接

弹层里七栏：连接名、核心地址、token、重连间隔（秒）、最大重连次数、绑定账号、排除账号。

- 绑定账号框与下面那组开关是**同一份数据**：框是手填入口（离线且从没绑过的号只能手写），开关是常规入口
- 弹层里的开关不即时保存，跟其余字段一起提交；中途关掉等于没改
- 地址填成 `host:port` 而一个账号都没开时，保存按钮会灰掉并在下面说明理由
- token 栏留空表示不修改

## 设置页与过滤页

两页的项与[配置](./config.md)一一对应，含义在那页说，这里只说在哪：

| 页 · 节 | 项 |
| :--- | :--- |
| 设置 · 总开关 | `enable`、`log_truncate`、`notify_master` |
| 设置 · 媒体与外链 | `media_max_size`（MB）、`file_max_size`（MB）、`link_expire`（秒）、`upload_hook` |
| 设置 · 内置文件服务 | `file_server` 的 `enable`、`port`、`host`、`public_host`、`once`、`imagebed_token` |
| 设置 · 更新检查 | `update_check` 的 `enable`、`interval`、`delay`、`notify` |
| 过滤 · 上报开关 | `report_private`、`report_group`、`report_meta`、`only_reply_at` |
| 过滤 · 前缀与关键词 | `prefix`、`block_prefix`、`block_include` |
| 过滤 · 群名单 | `white_group`、`black_group` |
| 过滤 · 用户名单 | `black_user` |

`bot_id_map` 不在面板上，它是张映射表而不是一栏值，只能改配置文件。设置页底下会显示配置文件的完整路径。

### 三栏的单位

`media_max_size` / `file_max_size` 按 **MB** 填，`link_expire` 按**秒**填，配置文件里仍然存字节 / 毫秒。改动过的大小栏，说明里会直接报出保存后会落盘的字节数，方便和 yaml 对照。

- 除不尽的值只显示两位小数（5000000 字节显示成 4.77 MB）。**没动过的栏保存时原样留着**，不会因为四舍五入被挪成 5001708
- 两个大小栏显示的是**生效值**：这两项写 0 等于「没配」、下游按默认值跑，所以面板显示的也是那个默认值而不是 0。代价是从没配过的人一按保存会把默认值写进 yaml —— 值一样，行为不变

### 名单栏怎么填

前缀、屏蔽词、群号、用户 ID 这几栏是**标签输入**：敲完按回车、或者打个逗号（中英文都认），就成一个标签；每个标签自带 `×`，输入框空着时按 Backspace 删掉最后一个。重复值静默去掉。

不做任何清洗 —— 前缀里的 `#`、关键词里的空格与大小写都参与匹配，差一个字就对不上。

群和用户还能**从已知列表里挑**：点「从群列表里挑」/「从好友列表里挑」开弹层，能搜索。这份列表在**点开的时候才拉**，不跟着页面的定时刷新走。列表是所有在线账号已知的群 / 好友，**账号离线时点开是空的** —— 这时候存着的名单不会丢，只是显示成光秃秃的号码、查不到名字。手输和挑选写进的是同一份数据，不是两份。

## 保存的两种节奏

- **开关拨一下就写**，立刻生效
- **数字、文本、名单要按保存**：底下会浮出一条「有 N 项未保存」，右边是保存 / 放弃

内置文件服务那一节**整节都要按保存**，连开关也不即时写：`port` / `host` / `public_host` 是一个意图，先把 `enable` 写进去会按旧端口重启一次、填完端口再重启一次，而每次重启都会作废还在途中的外链。

改了 `port` 或 `host`，保存后文件服务自动重启，提示条里会报出实际端口（`port: 0` 是随机端口，不报你看不到）。重启会让已经发出去的外链失效，最长影响一个 `link_expire` 的窗口。`public_host` / `once` / `imagebed_token` 是每次请求现读的，改完不重启。

`upload_hook` 保存时会试着加载一次那个模块，检查默认导出是不是函数，不是就连原因一起报错、不落盘。

改配置走的是和指令同一条路径，**yaml 里的注释会保留**。一处例外：心跳那两项改了会自动重连一次。

## 面板看不到 token

接口只回「配没配」这一个布尔值，**从不回原值** —— 卡片上显示成「已配 token」，编辑时留空表示不改动。地址也是脱敏后才回给浏览器：查询串、fragment 一律砍掉，每条 ws 只给到路径那一段。截图发出去不会连带把凭据发出去。

`file_server.imagebed_token` 走同一套：输入框留空表示不修改，真要清空得点旁边的「清除」。

## 手机上也能用

720px 以下换一套排布：卡片的按钮组整组换行靠右，机器人行从四列改成三列 —— 头像与开关钉在两端，平台、在线状态这些挪到昵称下面一行。开关的触控区固定 44px 高。禁用理由一律写成**可见**文字而不是悬浮提示：触屏上没有 hover。

## 锅巴那边

配置项与上面这个面板大体一致，少了内置文件服务那一节和 `upload_hook`（那几项只能在这个面板或配置文件里改）。改完同样即时生效、注释保留。

- 连接列表是**整表写回**：没动过的连接会原地留着，不会跟着断一次；保存后会自动把绑定账号补进 `bot_id_map`。只有心跳那两项改动会重建全部连接
- 群黑白名单用的是锅巴自带的群选择器（和云崽 `other.yaml` 里那两项同一个控件）。账号离线时点开是空的 —— 存着的群不会丢，只是查不到群名
- 用户黑名单在锅巴上是**两栏**：「好友里选」是好友选择器，「手动填」收手输 ID，两栏合起来写进同一个 `filter.black_user`。分两栏是因为选择器只能从好友表里挑，而 QQBot 官方号只有私聊过的人才在那张表里 —— 群里刷屏那位根本挑不到。保存后能在好友列表里查到的会挪进上一栏，只是显示位置变了，名单本身没动
