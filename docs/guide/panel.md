# Web 面板

装了 **QQBot-Web-Adapter** 的话，它的控制台左侧会多一页「早柚核心适配器」☄️，连接状态与配置都能点着改。装了[锅巴](https://github.com/guoba-yunzai/guoba-plugin)也可以在锅巴面板里改配置。

## 面板里有什么

- 连接的实时状态
- 今日 / 累计中转计数
- 连接的增删改与启停
- 全局设置

页面里用的是插件自己的图标；导航栏那颗只能是 emoji，宿主按纯文本渲染它。

## 不是自带服务器

::: warning 面板不自带服务器
它是挂在 **QQBot-Web-Adapter** 这个宿主上的插件页。宿主没装时这部分就是死代码，不影响插件其余功能。
:::

宿主开机时扫 `webadapter/index.js` 并注册页面与接口，接口由宿主统一加登录鉴权——非内网直接 403。也就是说鉴权不是插件自己做的，跟着宿主那一套走。

## 改配置的行为

改配置走的是和指令同一条路径，**yaml 里的注释会保留**。

两处例外要知道：

- `enable` 改了要重启云崽
- 心跳参数改了会自动重连一次

token 在面板上只显示「已配 token」，不回原值，留空保存表示不改动。
