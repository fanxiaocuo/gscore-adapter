# 指令

全部限主人使用。`#` 可以省略，`早柚` 后面加不加「核心」都一样（`#早柚状态` = `早柚核心状态`）。

## 最常用的几条

| 我想…… | 发这条 |
| :--- | :--- |
| 看连上没有 | `#早柚状态` |
| 连上一个核心 | `#早柚添加连接 127.0.0.1:8765` |
| 让另一个号也接进这个核心 | 在**那个号**上发 `#早柚添加连接 <同一个地址>` |
| 改配置 | `#早柚设置`（不带参数，会出图列出所有可改项与各自的改法） |
| 断了要恢复 | `#早柚重连` |
| 更新插件 | `#早柚更新` |

## 全部指令

**看状态**

| 指令 | 说明 |
| :--- | :--- |
| `#早柚状态` | 各连接状态、中转计数（出图）；一条连接绑了多个号时按账号列出每个号 |
| `#早柚连接列表` | 只列连接及其实时状态，绑定账号显示为头像胶囊（出图） |
| `#早柚帮助` | 指令一览（出图） |
| `#早柚版本` | 插件版本、发布类型与本机运行环境（出图） |
| `#早柚更新日志` | 本地已有的提交记录（出图） |

**管连接**

| 指令 | 说明 |
| :--- | :--- |
| `#早柚添加连接 <地址>` | 添加并立即启动。只填 `host:port`，不要带路径；不写 `bind=` 时默认绑发指令的那个号 |
| `#早柚修改连接 <名字或序号> <改动>` | 改已有连接，见下面的参数表 |
| `#早柚删除连接 <名字或序号>` | 删掉整条 |
| `#早柚开启连接 <名字或序号>` | `启用连接` 同义 |
| `#早柚关闭连接 <名字或序号>` | `停用连接` 同义 |
| `#早柚重连` | 重连全部连接。重连次数用尽后靠它恢复 |

序号就是 `#早柚连接列表` 里行首那个数字，从 1 开始。

**改配置**

| 指令 | 说明 |
| :--- | :--- |
| `#早柚设置` | 不带参数，出图列出当前所有配置及各自的改法 |
| `#早柚设置<项目><开启/关闭>` | 中文写法，可设：适配器 / 仅响应at / 私聊上报 / 群聊上报 / 事件上报 / 断线通知 / 更新检查 |
| `#早柚设置最大媒体大小 2` | 单位 **MB**，可以带小数。超过这个体积的媒体改用外链，最多 256 |
| `#早柚设置 <项>=<值>` | 英文写法，可设 `enable` / `only_reply_at` / `report_private` / `report_group` / `report_meta` / `notify_master` / `media_max_size` / `update_check`（开关定时检查）。注意这里的 `media_max_size` 按**字节**收 |

开关词认「开启 / 启用 / 打开 / 开」与「关闭 / 停用 / 禁用 / 关」，`on` / `off` / `true` / `false` 也行。可以连着写多项：`#早柚设置私聊上报关闭群聊上报开启`。

其余配置项（`file_max_size`、`link_expire`、文件服务、过滤名单……）没有中文指令，去[面板](./panel.md)或[配置文件](./config.md)改。

**其它**

| 指令 | 说明 |
| :--- | :--- |
| `#早柚检查更新` | 拉一次远端，看有没有新提交 |
| `#早柚更新` | 拉取更新（`#早柚强制更新` 覆盖本地改动） |
| `#早柚清空统计` | 清掉中转计数（今日与累计一起清）。平时那份计数跨重启保留 |

::: tip 出图拉不起浏览器时会降级成文本
出图要用框架的 puppeteer。浏览器起不来时自动回落成纯文本，内容是同一份，只是没有排版。
:::

改配置的指令全部即时生效，不用重启云崽，yaml 里的注释也不会丢。

## 添加 / 修改连接能带哪些参数

写在地址后面，用空格隔开，顺序随意。`=` 也可以写成 `:` 或中文冒号。

| 参数 | 意思 |
| :--- | :--- |
| `n=名字` | 连接名，日志和状态图上显示的就是它 |
| `t=口令` | token，核心那边配了鉴权才需要 |
| `bind=账号1+账号2` | 要接入这个核心的机器人账号 |
| `exclude=账号` | 不让这些账号走这条连接，比 `bind` 优先 |
| `id=平台标识` | 把当前绑定账号的平台记进 `bot_id_map`，如 `qqgroup`。得先有绑定账号才能用 |
| `url=地址` | 换核心地址。添加时直接写地址就行，用不上这个 |
| `enable=true` / `false` | 启用 / 停用这条连接 |
| `interval=5` | 重连间隔（秒） |
| `retry=5` | 最大重连次数，`0` 为一直重连 |

改账号名单时 `bind` 支持三种写法：`bind+=账号` 追加、`bind-=账号` 移除、`bind=账号1+账号2` 整体替换。`exclude` 同语法。多个账号之间用 `+`、`|`、`;`、`、` 隔开都行。

## 例子

```
#早柚添加连接 127.0.0.1:8765
#早柚添加连接 127.0.0.1:8765 n=主核心 t=abc
#早柚添加连接 127.0.0.1:8765 bind=2463381624+3889017463   ← 一次绑两个号
#早柚修改连接 1 bind+=2463381624      ← 给同一个核心再绑一个机器人
#早柚修改连接 1 bind-=2463381624      ← 让这个号不再接这个核心
#早柚修改连接 1 id=qqgroup            ← 把当前绑定账号的平台记进 bot_id_map
#早柚设置私聊上报关闭
#早柚设置最大媒体大小 2
```

地址只填到 `host:port`，**不要带 `/ws/Yunzai`** —— 那段路径由插件按绑定账号自己拼，理由见[配置](./config.md#多个账号接同一个核心)。填 `http://` 会被挡下来，并把地址换算成 `ws://` 的形式提示你重发。

## 多个机器人号接同一个核心

- **地址只填 `host:port` 的连接至少要绑一个账号**：核心侧就是靠 `/ws/Yunzai-<账号>` 这条路径认客户端的，一个账号都没有等于这条连接不存在。`bind=` 留空、`bind-=` 把最后一个移空都会被拒并告诉你理由（`bind=all` 已不再支持）
- **添加连接时**默认只绑「发这条指令的那个机器人号」。别的号要进同一个核心，就在那个号上再发一次 `#早柚添加连接 <同一个地址>`，会并进同一条连接；或者对现有连接 `bind+=` 追加
- 一个绑定账号一条 ws。用指令改 `bind` 会把这条连接的全部 ws 先停后起，回复里报「运行时连接：N 条」—— **只想动一个账号**而不打扰同一核心上的其他账号，用[面板](./panel.md)的账号开关
- 改动后如果和另一条连接撞了（同一个核心 + 同一个账号），会取消保存并告诉你撞上了谁

::: tip 地址里写了路径的连接不受「至少一个账号」的限制
`url` 写成 `ws://host:8765/ws/MyBot` 这种时只有一条 ws，`bind` 在它上头只是转发白名单，留空表示不限账号。两种连接的差别见[配置](./config.md#多个账号接同一个核心)。
:::
