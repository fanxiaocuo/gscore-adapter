# 指令

全部限主人使用，`#` 可省略。

## 指令一览

| 指令 | 说明 |
| :--- | :--- |
| `#早柚状态` | 运行模式、各连接状态、中转计数（出图）；子行还带该账号的收发数与心跳年龄 |
| `#早柚连接列表` | 只列连接及其实时状态（出图） |
| `#早柚帮助` | 指令一览（出图） |
| `#早柚版本` | 插件版本、发布类型与本机运行环境快照（出图） |
| `#早柚更新日志` | 本地已有的提交记录（出图） |
| `#早柚重连` | 重连全部客户端连接 |
| `#早柚添加连接 <核心地址>` | 添加并立即启动，只填 `host:port` 即可（`ws://` / `wss://`，不要带路径）；可追加 `n=名字` `t=token` `id=平台标识` `bind=账号1+账号2` `exclude=账号`。不写 `bind=` 时默认绑发指令的那个账号；同一核心再加号会并进已有连接的 bind |
| `#早柚修改连接 <名字或序号> <key=value>` | 改已有连接。`bind+=账号` 追加、`bind-=账号` 移除、`bind=账号1+账号2` 整体替换；`exclude` 同语法；也可改 `n` / `url` / `token` / `enable` / `interval` / `retry`；`id=` 按当前 bind 账号写入 `bot_id_map` |
| `#早柚删除连接 <名字或序号>` | 也可 `开启` / `关闭` 连接 |
| `#早柚设置` | 不带参数出图列出当前所有配置及各自的改法（`#早柚配置` 同义） |
| `#早柚设置<项目><开启/关闭>` | 中文写法，可设 适配器 / 仅响应at / 私聊上报 / 群聊上报 / 事件上报 / 断线通知 / 更新检查 |
| `#早柚设置最大媒体大小 2` | 单位 MB，超过这个体积的媒体改用外链 |
| `#早柚设置 <key>=<value>` | 英文写法仍然有效，注意 `media_max_size` 按字节收 |
| `#早柚检查更新` | 拉一次远端，看有没有新提交 |
| `#早柚更新` | 拉取更新（`#早柚强制更新` 覆盖本地改动） |

出图需要框架的 puppeteer 可用，拉不起浏览器时自动降级成文本。

::: tip 改配置会保留 yaml 原有注释
全部即时生效，不用重启云崽。
:::

## 例子

```
#早柚添加连接 127.0.0.1:8765
#早柚添加连接 127.0.0.1:8765 n=主核心 t=abc
#早柚添加连接 127.0.0.1:8765 bind=2463381624+3889017463   ← 一次绑两个号
#早柚修改连接 1 bind+=2463381624      ← 给同一个核心再绑一个机器人
#早柚修改连接 1 bind-=2463381624      ← 让这个号不再接这个核心
#早柚修改连接 1 id=qqgroup            ← 把当前 bind 账号的平台记入 bot_id_map
#早柚设置私聊上报关闭
#早柚设置最大媒体大小 2
```

地址只填到 `host:port`，**不要带 `/ws/Yunzai`**——路由段由插件按绑定账号在建连时生成，详见[配置](./config.md)。

## 多机器人绑定（bind）

- **地址填 `host:port` 的连接至少要绑一个账号**：核心侧的客户端标识就是 `/ws/Yunzai-<账号>`，一个账号都没有等于这条连接不存在。`bind=` 留空、`bind-=` 把最后一个移空、`bind=all` 都会被拒并给出这句理由（`bind=all` 已不再支持）
- **添加连接时**默认只绑「发这条指令的机器人账号」，其他号要进同一个核心，就在那个号上再发一次 `#早柚添加连接`（并进同一条连接的 bind），或对现有连接 `bind+=` 追加
- 一个绑定账号一条 ws。指令改完 `bind` 会把这条连接的全部运行时连接先停后起，回复里报「运行时连接：N 条」——只想动一个账号而不打扰同一核心上的其他账号，用[面板](./panel.md)的绑定开关
- `bind` 是账号白名单、`exclude` 是黑名单（优先级更高），两边都支持 `+` / `|` / `;` / `、` 分隔多个账号
- 每个 bind 账号都会单独写入 `bot_id_map`（平台标识）；`id=` 要先有绑定账号才能用
- 改动后若与另一条连接的核心地址加绑定账号重复，会取消保存并告诉你撞上了谁
- `#早柚连接列表` 出图时，bind 的账号显示为**头像 + 昵称**胶囊；[Web 面板](./panel.md)上每个账号一个开关，点一下即生效

::: tip 自定义路径的连接不受「至少一个账号」的限制
`url` 写了非根路径（如 `ws://host:8765/ws/MyBot`）时只有一条 ws，`bind` 在它上头是转发过滤器而不是路由来源，留空表示不限账号。两种连接的差别见[配置](./config.md)。
:::
