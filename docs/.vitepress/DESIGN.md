# 文档站视觉规范：液态毛玻璃（Liquid Glass）

> 2026-08-13 起生效，实现见 `theme/style.css`。
> 前一版是 MekaVerse 式发丝线极简（零阴影、零彩色、2px 半径），按用户要求整体换向；
> 旧规范里与风格无关的**中文可读性适配**全部保留，见文末。

## 三层结构

玻璃拟态的质感 = 玻璃后面有东西可糊。三层缺一不可：

### 1. 极光画布（canvas）

- 基底色落在 `html`：浅色 `#eef1f9`，深色 `#0c0f18`
- 色斑用 `radial-gradient` 铺在 `body::before / ::after`（fixed、z-index:-1）——
  径向渐变天然是软的，**不用** `filter: blur()`（整屏持续 GPU 开销）
- `::before` 是静层（三个大色斑定骨架），`::after` 是动层（两个小色斑做
  60s `transform` 漂移，ease-in-out alternate）。「液态」的标准：
  **看不出在动、离开再回来变了**
- `prefers-reduced-motion: reduce` 下动层停止

### 2. 玻璃面（glass surface）

统一配方：半透明底 + `backdrop-filter: blur() [saturate()]` + 1px 浅色描边
+ 顶部 1px 内高光（`inset 0 1px 0`）+ 环境软阴影。分三档：

| 档 | blur | 用在 | 透明度取向 |
| :--- | :--- | :--- | :--- |
| chrome | 20px + saturate 1.4–1.6 | 顶栏、侧栏、移动端菜单 | 最透（背后是画布） |
| card | 16px | 特性卡、弹层、搜索框、hero 相框、翻页卡 | 中等 |
| content | 10px | 代码块、表格、提示块、details | 最实 —— 正文可读性优先 |

- `saturate()` 让透过玻璃的色斑更艳，是「玻璃感」的一半
- **代码块透明度最保守**（浅色 62% 白、深色 62% 墨）：语法高亮的低对比色
  （注释灰）经不起色斑透底
- `@supports not (backdrop-filter)` 时三档一律退化成 88–94% 的近实底 ——
  宁可少一层质感，不能少可读性

### 3. 液态强调（accent）

- 主色与产品界面同源：`#5b7cfa`（webui 的 `--primary`），渐变收尾于相邻色相
  `#8b5cf6`：`linear-gradient(135deg, #5b7cfa, #8b5cf6)`
- 渐变只出现在：hero 标题字、h1 记号条、主按钮、提示块左侧条、outline 指示条。
  正文与普通标题**不用**渐变
- 链接色 + 下划线双保险（色觉障碍下仍认得出）

## 形状语言

- 半径：小件 8 / 卡片 16 / 大面 24 / 按钮与标签胶囊（999）
- 激活态用「面」不用「线」：导航 hover 是胶囊填充、侧栏激活是胶囊填充，
  不再是下划线 / 左侧竖线
- h1 记号条：3px 渐变圆头短条（clamp 72px–160px），每个 h1 都有、副标题没有 ——
  这是从旧版 underline mark 继承的品牌记号，只是换了语言

## 无障碍红线

- 正文对比度 ≥ 4.5:1，深浅两套分别核（玻璃底色透明度按此调）
- 色斑漂移、卡片 hover 上浮都尊重 `prefers-reduced-motion`
- 交互态不改变布局边界（transform-only）

## 保留的中文可读性适配（与风格无关，硬约束）

1. 正文 16px/1.8，窄屏回 15px；代码 13.5px/1.7
2. h1 `clamp(34px, 5vw, 46px)/1.08` —— 西文规范的超密行高会让方块字上下粘连
3. 导航 / 侧栏 / outline 无衬线 13.5px；等宽小字只给纯拉丁数字的角落
   （时间戳、表头、badge、侧栏分组标签 —— 「系统仪表」语气）
4. hero 左对齐；tagline 无衬线 15px（首页唯一一段完整中文说明）

## Don't

- 不在整屏元素上用 `filter: blur()`（用软渐变代替）
- 不把 `backdrop-filter` 铺到正文行内元素（只给面，不给字）
- 不让玻璃面叠玻璃面超过两层（弹层盖在 chrome 上是上限）
- 动效不超过 300ms（漂移画布除外，它是环境不是交互）
