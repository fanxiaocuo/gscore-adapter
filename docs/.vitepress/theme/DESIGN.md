# gscore-adapter 文档站设计规范

## 这份文档的由来

风格参考 [karin-plugin-kkk 文档站](https://karin-plugin-kkk-docs.vercel.app/)。
采集方法照 [design-md-chrome](https://github.com/bergside/design-md-chrome) 的思路
（采样可见元素 → `getComputedStyle` 聚合 typography/colors/spacing/radius/shadow/motion
→ 出频次），但那是个 Chrome 扩展、装不进这套工具链，所以用 CDP 跑了等效脚本，
并补了它没采的两项：**CSS 自定义属性本体**和**浅/深双主题**。

采集时间 2026-08-19。下面「参考站实测」一节是那次采集的原始结论，不是印象。

## 参考站实测（karin-plugin-kkk / Fumadocs）

变量前缀 `--color-fd-*`，即 Fumadocs，不是 VitePress。

| 维度 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#fafafa` | `#050505` |
| 正文 | `#0A0A0A` | `#fafafa` |
| 次要文字 | `#737373` | `#999` |
| 边框 | `rgba(153,153,153,.2)` | `#80808033` |
| 卡片 | — | `#0a0a0a` |
| accent | `#262626` | `#262626` |

- **字体** Inter，采样 22/22 个元素全是它，无第二字体
- **字号** 仅 6 档：16 主力、12、14、18、20、30
- **字重** 400 主力、500、600、700
- **行高** 16px→24px（1.5）
- **圆角** `9999px` 出现 7 次 + 24px 一次 —— pill 是它的标志元素
- **阴影** 聚合结果为空。分层全靠细边框
- **过渡** `0.15s cubic-bezier(.4,0,.2,1)`
- **导航条** 56px 高，背景**透明**，无 backdrop-filter
- **导航链接** `border-radius: 0`，**没有背景胶囊**，纯靠文字色区分状态

值得抄的三条：零彩色的克制、靠边框而非阴影分层、pill 只给按钮不给链接。

## 我们的取舍：抄手法，不抄颜色

参考站是**零彩色**的，本站要**盐系双档**配色 —— 这是直接冲突。取舍是抄它的
**手法**（状态指示、过渡时长、克制的字阶、大留白），颜色走自己那套。盐系本身
饱和度就低，和这种极简骨架并不打架。

玻璃三层结构（画布 / 玻璃面 / 强调）**保留**，没有推倒重做：`glass` 相关规则
在 style.css 里有 97 处、`box-shadow` 16 处，全拆的风险远大于收益。

## 配色 token

浅色「抹茶雾绿」，深色「奶雾蓝灰」。

| token | 浅色 | 深色 |
| --- | --- | --- |
| `--canvas-base` / `--vp-c-bg` | `#EEF5EA` | `#1E2A33` |
| `--color-accent` | `#5E7A56` | `#738FA3` |
| `--color-accent-2` | `#829E77` | `#9EB9C9` |
| `--vp-c-brand-1`（链接） | `#4E6848` | `#9EB9C9` |
| `--vp-c-text-1` | `#1E2A1B` | `#EAF0F4` |
| `--hero-gradient` | 同 accent | `#9EB9C9 → #C8DCE6` |

三个必须记住的陷阱：

1. **`--color-accent` 定义在无条件 `:root`**（那是浅色的绿）。`.dark` 必须覆盖它，
   否则蓝灰底上会冒出绿按钮。同理 `--vp-button-brand-*`。
2. **链接色不能直接用 accent**。`#5E7A56` 在 `#EEF5EA` 上只有 4.30:1，差 0.2 过不了 AA，
   所以链接压深一档到 `#4E6848`（5.6:1）。accent 仍用于按钮底、渐变 —— 那是大色块
   配白字，走 3:1 那条线。
3. **hero 大字深色下要单独提亮**。accent 那对在 `#1E2A33` 上是 4.3:1，过 3:1 但读着发糊，
   所以有独立的 `--hero-gradient`。
4. **别写死阴影颜色**。换配色时最容易漏的就是 `box-shadow: 0 6px 20px rgb(91 124 250/35%)`
   这类 —— 变量都换完了按钮底下还浮着一圈紫光。用
   `color-mix(in srgb, var(--color-accent) 32%, transparent)` 派生。

## 状态指示：用「线」不用「面」

导航链接、侧栏条目的 hover/active 一律是 **2px 指示线 + 文字色**，不用整片
半透明色块。两个理由：

- 色块比文字宽出一截，视觉重量压过内容本身
- 半透明色叠在流动色斑上，颜色会跟着背景漂

实现细节：指示线走伪元素 + `transform: scaleX/scaleY`，**不要**改 width 或
用 `border-left` —— 后者会改变内容盒宽度，激活时整行文字横跳 1~2px。

## 动效

- 过渡时长统一 `0.15s cubic-bezier(.4,0,.2,1)`（照参考站）
- 点击反馈统一 1px 位移：hover 抬起 `translateY(-1px)`，active 压下 `translateY(1px)`，
  来回 2px 行程足够明确又不晃眼
- 主按钮 active 时光晕收窄，模拟「贴近表面所以投影更聚」
- 侧栏 hover 时指示线探出一半（`scaleY(.5)`），暗示可点但不是当前项
- 色斑漂移尊重 `prefers-reduced-motion`

## 无障碍

目标 WCAG 2.2 AA。**实测**（CDP 取渲染后的前景色与沿祖先链找到的首个不透明底色，
不是拿纯色手算）：

| 元素 | 浅色 | 深色 |
| --- | --- | --- |
| 正文 | 10.22 | 10.09 |
| 正文链接 / 侧栏激活 / 导航激活 | 5.56 | 7.14 |
| 侧栏未激活 / 右栏大纲 | 8.43 | 9.29 |
| 分组标题 / 站点标题 | 13.47 | — |

无一项低于 4.5。改配色后必须重跑这个测量，别靠肉眼。

其余硬约束（与风格无关，来自中文排版）：

- 正文 16px/1.8，窄屏回 15px；代码 13.5px/1.7
- h1 用 `clamp(34px,5vw,46px)/1.08` —— 西文规范的超密行高会让方块字粘连
- 导航/侧栏链接 15px；侧栏分组标题无衬线 13px，中文分组不要等宽大写
- 等宽小字只给纯拉丁数字的角落（时间戳、表头、badge）
- `backdrop-filter` 不可用时（`@supports` 兜底）玻璃面退化成高不透明度实底

## Rules: Do

- 颜色一律从 token 取，组件规则里不写 raw hex
- 阴影颜色用 `color-mix` 从 `--color-accent` 派生
- 状态指示用线（伪元素 + transform），不用整片背景色
- 新增交互元素必须给全 default / hover / focus-visible / active 四态
- 改任何颜色后重跑对比度实测

## Rules: Don't

- 不要在 `.dark` 里漏掉 `--color-accent` 一族的覆盖
- 不要给导航/侧栏链接加 `--radius-pill` 背景面
- 不要用 `border-left` 做激活指示（会让文字横跳）
- 不要为了好看牺牲 4.5:1
- 不要整文件跑 `prettier --write`（本仓库 src 下有既有格式漂移，见根目录说明）
